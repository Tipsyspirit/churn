# User Guide

## Log in
Open the Streamlit app, choose Login or Register.

## Upload customers
Navigate to **Upload**. Provide a CSV with the 18 model features.
Rows that fail validation are listed with the reason.

## View predictions
**Customers** shows every scored customer. Search, filter, sort.

## Score one customer
**Predict** accepts a manual form. Output includes probability,
risk band, and a suggested action.

## Retention
**Retention** lists follow-up tasks. Assign, schedule, mark Retained/Churned.

## Model
**Model** displays the artifact details, threshold, and top features.
